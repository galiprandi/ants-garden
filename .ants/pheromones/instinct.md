## Cómo crear el PR

Después de hacer tus cambios y commits:

1. **Empuja la rama:** `git push -u origin <tu-rama>`
2. **Crea el PR:** `gh pr create --title "<título-descriptivo>" --body "<descripción-detallada>"`
3. Usa un título claro que describa el cambio
4. En el body incluye: qué hiciste, por qué, y qué archivos cambiaste
